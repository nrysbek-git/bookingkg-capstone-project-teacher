# CloudOps Academy infrastructure

The infrastructure as code lives in `terraform/`. Legacy Terraform and GitLab
CI files are not part of this repository.

## Architecture

- VPC across two availability zones
- public subnets for load balancers
- private subnets and NAT egress for EKS nodes
- isolated database subnets for PostgreSQL RDS
- two ECR repositories
- GitHub Actions authentication through OIDC
- application deployments in the `cloudops-academy` Kubernetes namespace

## One-time bootstrap

1. Create an encrypted, versioned S3 bucket for Terraform state.
2. Copy `terraform/terraform.tfvars.example` to
   `terraform/terraform.tfvars` and set `github_repository`.
3. Copy `terraform/backend.hcl.example` to
   `terraform/backend.hcl` and set the state bucket.
4. Authenticate locally to AWS, then run:

   ```bash
   terraform -chdir=terraform init -backend-config=backend.hcl
   terraform -chdir=terraform plan
   terraform -chdir=terraform apply
   ```

5. Add these GitHub repository variables under Settings > Secrets and
   variables > Actions > Variables:

   - `AWS_REGION`: `us-east-1`
   - `AWS_ROLE_ARN`: the `github_actions_role_arn` Terraform output
   - `TF_STATE_BUCKET`: the S3 state bucket name

6. Run the **Build and deploy** workflow. The frontend URL is shown by:

   ```bash
   kubectl -n cloudops-academy get service frontend
   ```

The database password is generated by Terraform and stored in AWS Secrets
Manager. Do not commit `terraform.tfvars`, `backend.hcl`, state files, or local
environment files.
