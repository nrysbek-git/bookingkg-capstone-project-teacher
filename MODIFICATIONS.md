# Modifications and Educational Adaptation

This repository contains the BookingKG travel-booking workload and its DevOps
and cloud-engineering training program.

The 2026 educational adaptation includes:

- BookingKG frontend, booking workflow and REST API adaptation;
- Docker and local container workflow;
- AWS and Terraform infrastructure exercises;
- Kubernetes and Amazon EKS deployment exercises;
- CI/CD and GitHub OIDC exercises;
- secrets, reliability, rollback and troubleshooting exercises;
- student assignment, acceptance criteria and instructor guidance;
- Russian and English educational documentation;
- evaluation and cloud-resource cleanup guidance.
